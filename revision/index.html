True or False — Sample

Study the statements on the question paper and decide which are true and which are false. Put a ‘✓’ in the suitable box. For the false statements, write down the mistakes and correct them.

1. Tin Ka Ping Secondary School locates in Fanling.

2. Coffee is a drink prepared from roasted cocoa beans.

True False Mistake Correction
1. ✓
2. ✓ cocoa coffee
提醒：答 False 的題目，除判斷真假外，還須寫出錯誤（mistake）並提供改正（correction）。
