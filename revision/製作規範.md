# 溫習資料製作規範（科目通用）

> 給接手的 AI：你要為**其他科目**做同系列的溫習資料。
> 這份文件只講「風格、結構、流程、底線」，不綁定任何一科。
> 中文科那 19 份已完成的檔案可作範例，但不要把它的內容規則照搬到別科。
> 最後更新：2026-10-25

---

## 1. 這批資料是甚麼

- **用途**：考試前的查閱工具。使用者已溫習過一輪，不是從零開始。
- **形態**：每個主題一個獨立的 HTML 檔，共用一份外部 CSS。
- **入口**：`revision\index.html`（全科範圍總覽）→ 各科索引 → 各份筆記。

由此推出三條硬規則：

1. **不要**倒數、進度條、「還有 X 天」、溫習時間表；
2. **不要**勵志語、心靈雞湯、長篇散文；
3. **要**可跳讀：表格化、小標題清楚、一節一個重點。

---

## 2. 設計語言

### 要

| 項目 | 規格 |
|---|---|
| 排版 | 單欄、最大寬 820–880px、置中 |
| 字體 | `system-ui` + 系統中文字（PingFang TC／Microsoft JhengHei），不用襯線 |
| 主色 | 藍 `#2563eb`；輔色深藍 `#1e3a8a`、琥珀 `#b45309`（警示） |
| 版面 | 白底；重要區塊用 `#fafbfc` 淡底 + 1px 邊 + 圓角 |
| 標題 | h1 有 2px 底線；h2 純文字；h3 灰色小字 |
| 表格 | 1px 灰邊、表頭淡底、`padding: 8px 11px` |
| 提示 | 左側 4px 色條 + 圓角右側（藍＝說明、琥珀＝警告） |
| 列印 | A4 友善：去陰影、區塊避免分頁 |

### 不要

- ❌ 漸變、玻璃擬態、霓虹色、動畫
- ❌ icon 字型、外部 CDN、Google Fonts（離線要能開）
- ❌ 每個檔案各自寫一套 CSS

## 3. 目錄與命名

```
revision\
├─ index.html            全科總覽（人看的入口）
├─ Chinese\              科目資料夾
│  ├─ index.html         該科細目
│  ├─ assets\notes.css   共用樣式
│  ├─ 自习篇章\ ...       主題資料夾
│  └─ ...
└─ _backup_xxxx\         備份（勿動）
```

**命名規則（重要）**

- 資料夾與檔名**一律用簡體中文**，例：`自习篇章\孟尝君列传.html`、`课文问答\种梨.html`、`成语\成语13-32.html`。
- 科目資料夾用英文：`Chinese\`、`English\`、`Math\`、`IS\`。
- 檔名用主題本身，不加日期、不加版本號（版本交給備份資料夾）。
- 不用空格；需要分隔時用連字號或範圍寫法（`成语13-32.html`）。

⚠️ 曾發生：子 agent 依「內容是簡體」而新建了 `课文问答\`，與 `課文問答\` 並存。**命名只看規則，不要看內容語言臨時決定。**

## 4. 樣式系統：`assets\notes.css`

一份 CSS 服務全科。引用方式（假設筆記在 `科目\主題\` 下）：

```html
<link rel="stylesheet" href="../assets/notes.css">
```

**不要**在 HTML 裡寫 `<style>`，**不要**為單一檔案改 `notes.css`。

### class 速查

| class | 用途 | 標籤 |
|---|---|---|
| `.doc` | 版面容器 | `<article class="doc">` |
| `.topnav` | 頁首導覽列 | `<nav class="topnav">` |
| `.kicker` | 最上方小標籤 | `<p class="kicker">` |
| `.meta` | 篇名下的資料行 | `<p class="meta">` |
| `.orig` | 原文／題幹／原始材料區 | `<div class="orig">` |
| `.note` | 小字備註 | `<p class="note">` |
| `.tip` | 提示框（重點、易錯、口訣） | `<div class="tip">` |
| `.ans` | 答案強調 | `<span class="ans">` |
| `.q` | 題目清單 | `<ol class="q">` |
| `.k` | 表格左欄標籤 | `<td class="k">` |
| `.n` | 表格窄欄序號 | `<td class="n">` |
| `.saying` | 佳句／金句／關鍵句 | `<blockquote class="saying">` |
| `.back` | 條目底部「↑ 返回」 | `<a class="back">` |

### 長檔案才用的錨點

```html
<h2 id="top">一、总表</h2>
<td class="k"><a href="#i13">条目名</a></td>
<h3 id="i13">13. 条目名</h3>
<a class="back" href="#top">↑ 返回总表</a>
```

## 5. 頁面骨架（通用模板）

把 `{{...}}` 換成該科內容即可：

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{{主题}}｜{{科目}}温习</title>
<link rel="stylesheet" href="../assets/notes.css">
</head>
<body>
<nav class="topnav"><a href="../index.html">← 返回索引</a></nav>
<article class="doc">

  <header>
    <p class="kicker">{{科目}} ｜ {{考试名称}} ｜ {{类别}}</p>
    <h1>{{主题标题}}</h1>
    <p class="meta">{{出处或章节}}　｜　{{页码或范围}}　｜　{{单元／模块}}</p>
    <p class="note">{{一句话说明这份笔记怎么用}}</p>
  </header>

  <h2>一、{{第一节}}</h2>
  <div class="orig"><p>{{原始材料}}</p></div>

  <h2>二、{{第二节}}</h2>
  <table>
    <tr><th style="width:9em">项目</th><th>内容</th></tr>
    <tr><td class="k">{{标签}}</td><td>{{内容}}</td></tr>
  </table>

  <h2>三、{{第三节}}</h2>
  <div class="tip">{{重点提示}}</div>

  <footer>{{科目}} {{考试名称}}（{{日期}}）{{类别}}温习材料</footer>
</article>
</body>
</html>
```

要點：

- `<body>` 後第一行必須是 `topnav`；
- `header` 三件套：`kicker` + `h1` + `meta`；
- 章節一律 `<h2>`，編號「一、二、三……」；
- 最後必須有 `<footer>`（寫明科目、考試、日期、類別）；
- 表格第一列用 `<th>`，左欄標籤用 `<td class="k">`。

## 6. 內容原則

### 6.1 準確優先於完整

- 引文**逐字照抄**，不改寫、不順句；
- 不確定出處就不寫出處（寧缺勿錯）；
- 課本／通告的說法即使看似矛盾，**照寫**，在旁加註即可，不要自行「更正」。

### 6.2 不要臆造

四類絕對禁止：出處、引文、數據、法規條文。
凡是「我記得好像是……」的內容，一律不寫。

### 6.3 以考法為綱

先問「這科怎麼考」，再決定筆記長甚麼樣：

| 考法 | 筆記重心 |
|---|---|
| 選擇題 | 對照表、易混淆點、一句速記 |
| 填充／短答 | 關鍵詞、標準句式 |
| 問答／論述 | 題目 + 參考答案 + 答題框架（立場／理由／扣題） |
| 計算／證明 | 例題 + 步驟 + 常見錯處 |
| 資料回應 | 資料摘錄 + 立場 + 論據 |

### 6.4 語言

- 內容語言依使用者指定（中文科現用**簡體**；英文科用英文）。
- 一份檔案內不要繁簡混用。
- 若內容用簡體，需保留**字形辨析**：簡體合併的字要用正體或讀音說明區分（例：骛／鹜、浃／夹、长 zhàng／cháng）。

## 7. 常用內容模組

| 模組 | 寫法 | 適合 |
|---|---|---|
| 對照表 | 兩欄或三欄 `<table>`，左欄 `td.k` | 原文／譯文、古今義、正確／錯誤 |
| 分類表 | 首列 `<th>`，每列一項 | 手法、題型、事件 |
| 提示框 | `<div class="tip">` | 易錯點、口訣、考試提醒 |
| 佳句／關鍵句 | `<blockquote class="saying">` | 名句、定義、法規原文 |
| 問答 | `<h3>` 題目 + `<p>` 答案 + `<p class="note">答题技巧` | 問答型科目 |
| 流程／步驟 | `<ol class="q">` | 計算步驟、實驗流程 |
| 待補區 | `tr.todo`（淡灰） | 尚未取得的資料 |

## 8. 素材怎麼處理

### 8.1 使用者給照片

一頁一張、字夠大、頁碼入鏡；跨頁處前後各拍一張。

### 8.2 使用者給 PDF（有文字層）

```powershell
python tools\pdftext.py "范围.pdf" "out.txt"
```

純標準庫（`zlib` + `ToUnicode` CMap），不需安裝任何套件。
抽出來是亂碼 ⇒ 該 PDF 無 ToUnicode，請使用者改為截圖。

### 8.3 使用者給 PDF 匯出的 HTML

```powershell
python tools\pdfhtml2txt.py "教材.html" "out.txt"
```

這類 HTML 每個文字片段都是絕對定位的 `div`（`transform:matrix(1,0,0,1,X,Y)`）。
工具已做兩件事：**先按 `<div class="page">` 切頁**（否則各頁座標重疊、文字互相穿插），再按 Y 分行、X 排序。
含合併儲存格的二維表格仍會交錯，需人工判讀。

### 8.4 全部都沒有

不要猜。請使用者提供素材，並說明你需要哪幾頁、為甚麼。

## 9. 交件前驗證

存成 `%TEMP%\verify.py` 執行（只改第一行的路徑）：

```python
import re, os
from html.parser import HTMLParser

p = r"要檢查的檔案.html"
s = open(p, encoding="utf-8").read()

VOID = {"meta","link","br","img","hr","input","nav"}
class P(HTMLParser):
    def __init__(self): super().__init__(); self.stack=[]; self.err=[]
    def handle_starttag(self,t,a):
        if t not in VOID: self.stack.append(t)
    def handle_endtag(self,t):
        if t in VOID: return
        if not self.stack: self.err.append("extra "+t); return
        if self.stack[-1]==t: self.stack.pop()
        else: self.err.append(f"mismatch {self.stack[-1]}/{t}")

pp = P(); pp.feed(s)
print("結構:", pp.stack or "OK", "| 錯誤:", pp.err or "無")
print("有 style:", "<style" in s, "| css:", 'href="../assets/notes.css"' in s,
      "| topnav:", 'class="topnav"' in s)
trad = "們這說時為後裏國學對開關問題實現認識東車馬長門間聞無書買賣讀學習寫語詞義應該經濟過錄歷際線組織團結極隻麼幾乾於"
print("繁體殘留:", {c: s.count(c) for c in trad if s.count(c)} or "無")
print("h2:", s.count("<h2>"), "| bytes:", os.path.getsize(p))
```

**通過標準**：結構無錯、無 `<style>`、css 與 topnav 齊、繁體殘留 0（若該檔用簡體）、`h2` 數符合預期、> 8000 bytes。

另外必做**連結檢查**（改名或搬檔後尤其重要）：

```python
import os, re
root = r"C:\...\revision"
bad = 0
for dp,_,fs in os.walk(root):
    if "_backup" in dp: continue
    for f in fs:
        if not f.endswith(".html"): continue
        p = os.path.join(dp,f)
        for l in re.findall(r'href="([^"]+)"', open(p,encoding="utf-8").read()):
            if l.startswith("#"): continue
            t = os.path.normpath(os.path.join(dp, l.replace("/", os.sep)))
            if not os.path.exists(t):
                bad += 1; print("BROKEN", p, "->", l)
print("失效連結:", bad)
```

## 10. 十個坑

1. **PDF 不是圖片**。模型能看圖，但 PDF 是二進位容器；沒有渲染器就看不到，沒有解析器就抽不出字。
2. **PDF 匯出 HTML 的座標是分頁的**。不分頁會疊字（曾出現「中國語文科中國語文科中國語文科」）。
3. **命名只看規則**。不要因為內容是簡體就把資料夾改成簡體（反之亦然）。
4. **日期要對星期**。學校文件寫「27/10/2026(四)」，但該日是**星期二**；已確認以日期為準，星期是筆誤。
5. **子 agent 會「補完」你的內容**（四字成語被擴成八字），還把錯誤寫成規則。交件後要逐條核對。
6. **給子 agent 任務時，把原始答案貼進提示**，不要讓它從碎片裏猜哪句是答案。
7. **`present` 每次最多 4 個檔**，且卡片逐回合顯示，早前的不會常留。
8. **沙箱會擋 pip**（`Errno 13`）。需要繁簡對照表時直接下載 OpenCC：
   `https://raw.githubusercontent.com/BYVoid/OpenCC/master/data/dictionary/TSCharacters.txt`
   格式：`正體<TAB>候選（空格分隔，取第一個）`。
9. **繁簡轉換只轉文字節點**。用正則切開標籤與文字，`href` 內的中文檔名不要轉，否則連結全斷；轉完要跑第 9 節的連結檢查。
10. **不要用「完成了」代替驗證**。先跑腳本，回報數字（bytes、h2 數、失效連結數）。

## 11. 新增一科的步驟

1. 建資料夾：`revision\English\`（英文名，簡體規則不適用於科目名）。
2. 複製 `Chinese\assets\notes.css` 到 `English\assets\notes.css`
   （或用相對路徑共用，但跨科引用較脆，建議各科一份）。
3. 建 `English\index.html`：該科細目頁，內嵌 CSS（可照 `Chinese\index.html` 改色）。
4. 按第 5 節骨架做各主題筆記，放進簡體命名的子資料夾。
5. 在 `revision\index.html` 對應科目那張卡補上「→ 筆記」連結。
6. 跑第 9 節兩段腳本。

### 各科要注意

| 科目 | 差異 |
|---|---|
| English | 內容用英文；`notes.css` 西文字體已夠；可用 `<em>` 標重點詞 |
| 中史／History | 時間線與因果表是核心；三欄式「事件／年份／影響」最實用 |
| IS／科學 | 需要 `code` 樣式（`notes.css` 未定義，自行加 3 行）；公式用行內排版 |
| Math | 現有 CSS 不足，建議另建 `math.css` 或改用純文字公式，勿強行塞入 |
